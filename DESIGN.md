# IntelNet Website Design System

## Visual language

The homepage uses a minimal premium software language: an immersive near-black opening, white product surfaces, a restrained blue-violet highlight, and large quiet spacing. The visual priority is product capability first, with the browser interface treated as the hero object rather than an illustration around the product.

## Tokens

- `--ink`: `#08090c`, dark hero and developer surface.
- `--paper`: `#f7f7f8`, reading surface.
- `--violet`: `#7566ff`, product highlight and active state.
- `--cyan`: `#b7f3ff`, quiet system signal.
- `--line`: `#e4e5e9`, light structural rule.
- Display face: Inter.
- Body face: DM Sans.

## Composition

The first viewport pairs a large thesis with a dimensional browser plate on a dark field. The assistant panel is the product-specific proof, not a decorative hero illustration. Scrolling moves into a clean white workflow demonstration, a dark developer architecture panel, and a direct project close.

## Interaction

The workflow tabs are the signature interaction. They preserve the browser frame while updating the assistant transcript and explanatory copy, making the mechanism legible without hiding content behind motion. Buttons use restrained positional feedback and preserve visible focus states through browser defaults.

## Responsive behavior

Desktop uses editorial two-column compositions. Below 850px, sections stack into a single reading path, navigation simplifies, and the browser demonstration keeps its assistant panel attached to the lower edge. At 500px, article metadata yields to the core page content and code rows become two-line entries.
